# Telegram bot scaffold

The bot will be the entry point to the Mini App and the support/notification layer.

## Planned commands
- /start — open the Mini App
- /menu — open the Mini App
- /orders — show order status
- /number — show active number
- /credits — show credits
- /support — support

## Notifications
- payment received / approved
- eSIM provisioning complete
- renewal reminder
- renewal overdue / service deactivation warning
- verification SMS received

The bot token must be stored only as an environment secret, never in GitHub.
